# Cedar Park Barbershop Website

High-conversion website redesign for **Cedar Park Barbershop** located in Cedar Park, TX (401 Cypress Creek Rd, Suite 300).

## Features
- **Premium Barber Aesthetic**: Custom copper/bronze & dark navy design system for classic gentleman's grooming.
- **Service Menu & Transparent Rates**: Detailed pricing for signature cuts, fades, beard sculpts, and hot towel shaves.
- **Click-to-Call & Booking Integration**: Direct actions for online appointment booking and (512) 294-2516 call routing.
- **Local SEO & Schema.org**: Pre-configured `BarberShop` structured data for Google Search and local map rankings.
